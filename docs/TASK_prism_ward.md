# Prism Ward — щит из материи пространства (Metroman, LVL 40)

Пакет `com.invfix.prismward`. Щит Стрэнджа из боя с Таносом: прозрачная плоскость
пространства, видимая только в момент удара.

## Требования (заданы)
- Metroman (Alien(Metroman)), LVL 40. Shift + клавиша способности — меню.
- Статичный щит на клавишу: квадрат 2×2…6×6, дальность 1–60, плоскости как у
  Mystic Portal (на грани блока — её плоскость, в воздухе — по углу взгляда).
- Стоит, пока не уберут. Режимы: «Расставка» (сколько угодно, кнопка «Убрать все») и
  «Замена» (новый убирает прежние).
- Прочность (HP): любое число, 0 — неуязвим. Не выдержал — разлетается стеклом.
- Твёрд для всех и всего: сущности, снаряды, урон из-за щита (кроме пустоты).
- Снаряд отскакивает как от стены; кто не умеет отскакивать — разрушается, как при
  попадании. Зеркало: обратно, откуда прилетел, с той же скоростью; Point Blank
  (снарядов нет) — пуля возвращается стрелку.
- Self Shield (тумблер в меню): по принципу модуля щита, бесплатно, весь урон кроме
  пустоты; своё зеркало. Клавиша способности на него не влияет.
- Графика: сущность невидима всегда (и хитбокс). Реакция — только при взаимодействии:
  урон, снаряды, касание (малая локальная). Эффект — преломление, локально, по кадрам
  фильма (грани, радужное расслоение, золотые искры; разрушение — стеклянные осколки).
- Порталы и щит — совместимость с Create Big Cannons, аддонами и библиотеками.

## Как сделано
| Что | Где |
|---|---|
| Хранение (переживает рестарт) | `PrismWardData` (SavedData измерения) |
| Сущность (невидима, не сохраняется) | `PrismWardEntity`, рендерер `PrismWardClient.WardRenderer` |
| Твёрдость для сущностей | `EntityWardCollideMixin` → `PrismWardBarriers.collide` (своя, ваниль ищет сущности-препятствия с запасом 2 блока — щит 6×6 у краёв терялся бы) |
| Снаряды (любой `Projectile`, CBC, ракеты MW) | `PrismWardHandler.onEntityTick` (EntityTickEvent.Pre), `WardProjectiles` |
| Урон из-за щита, Self Shield | `PrismWardHandler.onIncomingDamage` (NORMAL — раньше модуля щита) |
| Взрывы | `PrismWardHandler.onDetonate` (блоки и сущности за щитом) |
| Лучи (Heat Vision и пр.) | `PortalBeams.trace` — луч кончается у щита; урон/огонь/взрыв Heat Vision не дальше щита |
| Energy Blast | отскок / зеркало в `EnergyBlastHandler.fly`; урон взрыва — от точки взрыва |
| Point Blank | `PbHitScanWardMixin` (урон щиту — только выстрел, не наведение ракет); ракеты — `PbRetarget` |
| Шрапнель RPL | `BurstSubProjectileMixin` |
| VFX | `PrismWardFx` (один эффект на все щиты), `prism_ward.fsh`, `prism_shatter.fsh`; узор трещин — `prism_glass.glsl` (радиальные трещины от точки удара + неполные кольцевые, угловатые осколки, у каждого своё преломление, радужная кайма на изломах) |
| Рамки (только владелец, вкл/выкл в меню) | `PrismWardFrames` (владелец — в данных сущности) |
| Кратеры и разрезы не проходят за щит | `WardOcclusion`: лучи BMNW (Energy Blast), `ComboImpact`, `KineticCrater`/`KineticNuke`, Dismantle, Space Fold |

## Порталы и CBC
`PortalPass`: снаряды CBC/MW трассируют весь отрезок тика сами (`clipAndDamage`) и били
стену за порталом раньше переноса ядром IP; к тому же ядро IP берёт только сдвиг ≤ 16
блоков. Теперь перенос — в начале трассы тика (`CannonProjectilePortalMixin`,
`MunitionContraptionPortalMixin`, шрапнель — `BurstSubProjectileMixin`).

## Ограничения (известные)
- Урон снаряда по HP щита — по исходникам для ванильных снарядов и CBC; неизвестный
  снаряд — 1. Пуля Point Blank — без спада по дальности и хедшота.
- Лучи Heat Vision снимают с щита только видимую реакцию, не HP.
- Ракета MW через портал: точка/скорость/угол поворачиваются, сборка блоков — нет.
